# VERLORAY Run 60 — Policy Is Not Capability

## Customer Truth
A governance rule that says an action is allowed is not proof that the connector, credential, permission, spend control, approval path, and runtime needed to execute that action are actually configured.

## Creative Strategy
**Hook:** A policy can authorize an action. Only a verified runtime can prove the action exists.

**Body:** VERLORAY’s strongest buyer story is governed orchestration: research, boardroom debate, objectives, plans, budgets, approvals, project state, and execution boundaries in one visible control plane. The HAP constitution now makes the key distinction explicit: an allowable action becomes executable only when the required connector, credential, permission, spending limit, approval rule, and runtime path are configured and verified.

**CTA:** Inspect the control plane first. Then connect only the capabilities you are prepared to authorize.
