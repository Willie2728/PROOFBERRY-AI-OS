# RUN111 — Another You: Trust Before Outreach

## Customer Truth
A supervised AI-workforce pipeline should not begin with “Can the agent apply?” It should begin with “What must be checked before the agent is allowed to act on this opportunity?” The operating product already modeled opportunity-source verification, but the acquisition proof brief did not ask the buyer to define that trust check.

## Creative Strategy
**AY-TXT-002 — Trust Before Outreach**

Hook: **Before the AI applies, verify what it is applying to.**

CTA: **Build one trust-and-proof brief before registration.**

## Production Readiness
The no-contact first-pipeline brief now asks for four structured decisions:
1. work type;
2. source/client trust check before outreach;
3. human approval boundary;
4. external/system receipt that would count as completion.

`PipelineScopeSignal` now includes `source_verification_requirement` with structured values for source review, client identity confirmation, platform contract/order confirmation, direct-client scope/authority verification, or an explicit unresolved state.
