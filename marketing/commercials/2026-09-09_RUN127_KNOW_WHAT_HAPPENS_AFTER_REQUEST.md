# ProofBerry RUN127 — Know What Happens After the Request

**Asset:** PB-TXT-137  
**Customer Truth:** A qualified buyer should not have to guess what submitting a one-role review request actually triggers.

## Creative Strategy
**Hook:** A qualified request should not open a black box.

**Body:** ProofBerry records the scoped request first. A human can then review the buyer-defined role, evidence boundaries, and evaluation plan and follow up if there is a fit. Submitting is not pilot acceptance, scheduling, budget or authority verification, a response-time guarantee, candidate verification, or a hiring outcome.

**CTA:** Request the one-role review only when the buyer understands what the request does — and does not — trigger.
