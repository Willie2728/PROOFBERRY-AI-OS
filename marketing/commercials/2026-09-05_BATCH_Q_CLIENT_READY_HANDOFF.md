## PB-TXT-026 — Recruiter / Staffing LinkedIn

**Status:** production-ready; not published.

AI can help process more applications. That does not automatically make the candidate handoff easier to defend with a client.

ProofBerry is being built around a simpler idea for staffing teams: when you present a candidate, make the underlying evidence easier to inspect.

One live role. One set of role-relevant criteria. Candidate work or structured responses. Follow-up reasoning. A recruiter note that says what matters and what still needs review.

Then the client and recruiter keep the decision.

That is the design-partner workflow we want to test with staffing teams: **candidate + evidence handoff, not candidate + mystery score.**

Request early design-partner access for one live role.

## PB-TXT-027 — Short Recruiter Post

**Status:** production-ready; not published.

A staffing client should not have to ask, “Why this candidate?” and receive only a résumé plus a score.

ProofBerry’s early-access direction is a reviewable handoff:

**criterion → evidence → follow-up reasoning → recruiter note → human decision**

If you run a staffing or recruiting team, we are looking for design partners willing to test that workflow on one live role.
