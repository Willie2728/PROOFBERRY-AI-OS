# Run 28 Customer Truth — Evidence Provenance

Date: 2026-09-05
Audience: staffing agency owners, recruiting leaders, client-facing recruiters, hiring-team design partners

## Customer truth

**A verification label is not enough. The client needs to know what kind of evidence it is and where it came from.**

Current 2026 staffing-market evidence supports the buyer problem without proving a ProofBerry outcome. StaffingHub reported on April 28, 2026 that 65% of surveyed hiring managers said AI-enhanced resumes made candidate skills harder to verify and argued that staffing firms should proactively explain their validation methodology to clients. Current competitive products are also moving toward cited or source-linked evidence rather than an unexplained score or badge.

The resulting proposed one-role design-partner method is:

`role signal → provenance label → supporting artifact → reviewer note → unresolved question → client review → human-owned decision`

Suggested provenance labels:
- Candidate-stated
- Demonstrated
- Recruiter-observed
- Third-party checked, when actually available
- Unresolved

## Why this is different from Run 27

Run 27 made the verification *method* visible. Run 28 makes the *source of each evidence item* visible. That is a stronger client-handoff concept because a reviewer can distinguish a claim, a demonstration, a recruiter observation, an external check, and an open question instead of treating them as equivalent.

## Product-truth boundary

Connected ProofBerry currently contains 0 `RubricCriterion` records. The provenance chain is therefore an early-access pilot method and buyer-facing specification, not a claim of a finalized live rubric, identity-verification product, legal/compliance certification, bias elimination, predictive validity, placement improvement, ATS integration, ROI, or automatic hiring.

## Conversion decision

Keep the existing recruiter landing architecture stable. Test the provenance message through attributable staffing traffic before adding another funnel variant. Primary CTA: **Bring one live role and label the evidence before you score it.**
