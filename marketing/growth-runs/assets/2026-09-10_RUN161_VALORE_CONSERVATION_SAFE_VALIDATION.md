## Customer truth
A security concept for high-value art has to earn trust without making the original artwork the first validation surface. The qualified review path should require a sacrificial mock-up, conservator-approved surrogate, or vendor bench fixture before an original-art contact discussion can advance.

## Deployable owned copy
The first security test should never use the artwork as the test surface. Choose one threat, one conservation-safe validation surface, one expected event receipt, one accountable conservation/security reviewer, and one advance rule. A bench result can justify the next review; it cannot by itself prove original-art safety.
