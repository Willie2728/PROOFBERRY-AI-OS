## 1. ProofBerry AI

### Customer Truth

Run 25 moves the staffing design-partner wedge from generic skills-first positioning to a concrete operating artifact:

**Skills-first hiring needs an evidence specification.**

Current hiring research and staffing automation trends point in the same direction. Skills-based hiring is becoming more common, while staffing software is automating more sourcing, screening, and client-submission work. The remaining buyer question is not simply whether skills matter; it is what role-relevant evidence the client should actually be able to inspect before a score or summary is trusted.

Run 25 therefore defines the one-role pilot around:

`role criterion → acceptable evidence → follow-up question → recruiter reviewer note / uncertainty → human decision owner`

Critical product-truth boundary: the connected ProofBerry Base44 app currently contains **0 RubricCriterion records**. Run 25 therefore does not market a finalized live rubric or independently validated scoring system.
