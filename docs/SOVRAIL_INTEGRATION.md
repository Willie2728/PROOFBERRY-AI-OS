# SOVRAIL Integration — PROOFBERRY AI OS

PROOFBERRY should use SOVRAIL for applicable interview, coaching, job-matching, training, and external AI/API work.

## Benefits
- Centralize provider credentials and protect them from client applications.
- Use cheaper/local models for repetitive classification, extraction, formatting, and routine coaching scaffolds when appropriate.
- Reserve premium models for nuanced interview analysis and high-value feedback.
- Reuse safe job-description, competency, rubric, and training workflow components through Adaptive Recipe Memory.
- Add per-organization/per-candidate budgets, usage visibility, and approved-provider failover.

## Runtime
PROOFBERRY workflow -> SWARMER policy -> SOVRAIL execution -> approved model/API -> KAMERON checkpoint for recoverable sessions.
